# Built-in ImageGen gameplay prompts

All four source sheets were generated with the built-in ImageGen tool. No SVG or
programmatic drawing is used in the final gameplay sprites. The processing script
only crops, cleans alpha, resizes, mirrors ImageGen samples for repeatability, and
places them on transparent canvases.

## Slot family

Use case: stylized-concept. Asset type: Unity mobile puzzle-game modular gameplay
sprite source sheet. Generate four isolated pieces for one narrow vertical empty
sorting slot: a three-scallop top cap, a rectangular seamless repeatable middle
wall, a rounded bottom foot, and an oval shadow. Use a true transparent background,
front-facing orthographic toy-plastic rendering, deep indigo cavity, dark navy
outline, violet bevel, top-left highlight, equal piece widths, no text, icons,
cubes, ice, cover, perspective, or watermark.

## Ice family

Use case: stylized-concept. Asset type: Unity mobile puzzle-game ice obstacle
source sheet. Generate a separate horizontal frost band and three separate hanging
icicle clusters (left, longer center, right). Use true transparency, front-facing
orthographic 2.5D casual-game art, chunky faceted translucent aqua ice, frosty pale
blue rims and white glints. Keep all four objects fully isolated; no slot, cover,
text, symbols, background scene, checkerboard, or watermark.

### Ice crystal refinement

Use case: stylized-concept. Generate exactly three separate simple hanging
icicle shards: a short slightly left-leaning shard, a 15% longer straight center
shard, and a short slightly right-leaning shard. Each is one chunky tapered
crystal with a clean flat hidden attachment edge and a single pointed tip. Use
true transparency, broad readable aqua facets, front-facing orthographic game
art, and restrained internal cyan glow. No snow caps, frost band, clusters,
extra tips, background, checkerboard, text, symbols, or watermark.

## Cover family

Use case: stylized-concept. Asset type: Unity mobile puzzle-game modular covered
column source sheet. Generate a rounded horizontal top cap, a rectangular seamless
repeatable one-cell cover with straight rails and flat cut edges, and a thin
separator. Use true transparency, front-facing orthographic molded beige/taupe
plastic, brown-purple outline, subtle lower/right bevel and top-left highlight.
Keep widths consistent; no text, icons, cubes, ice, perspective, or watermark.

## Mystery family

Use case: stylized-concept. Asset type: Unity mobile puzzle-game mystery cell
source sheet. Generate one blank square dark toy-plastic face plate and one separate
bold warm-white question-mark decal with a charcoal outline. Use true transparency,
front-facing orthographic 2.5D casual-game rendering and top-left light. The tile
must remain blank and the question mark must not touch it. No other symbols, text,
background scene, perspective, or watermark.
