# Built-in ImageGen UI icon prompts

All icons were generated as independent raster images with the built-in ImageGen tool. The four supplied screenshots were used only as visual-style references. Every prompt requested genuine transparency, no text, no watermark, no button shell, and no SVG/vector source.

Shared style direction: polished 3D plastic mobile puzzle-game UI, chunky friendly geometry, soft bevels, upper-left glossy lighting, restrained lower-right depth, warm cream `#FFF4D4`, dark-purple outline `#35266F`, centered square composition, safe transparent padding.

## `Icons/restart.png`

Create one clean clockwise circular restart arrow as a standalone raster sprite: exactly one continuous open-loop arrow body and exactly one arrowhead in the upper-right quadrant following clockwise flow. Cream fill, thick smooth dark-purple outline. No extra arrowheads, fragments, detached pieces, secondary ring, text, or background.

## `Icons/close.png`

Create one friendly chunky X glyph with four rounded ends, balanced diagonals, cream fill, and thick smooth dark-purple outline. No circle, tile, plus sign, text, or background.

## `Icons/profile.png`

Create one simple user bust silhouette: one round head above one rounded shoulder/chest shape, no face. Cream fill with thick smooth dark-purple outline. No badge, tile, extra people, text, or background.

## `Icons/sound.png`

Create one speaker cone facing right with exactly two curved sound-wave arcs. Cream fill with thick smooth dark-purple outline. No music note, microphone, mute slash, tile, text, or background.

## `Icons/vibration.png`

Create one upright rounded smartphone with exactly two short curved vibration marks on each side. Cream fill with thick smooth dark-purple outline. No screen glyph, notification symbol, slash, tile, text, or background.

## `Icons/off_slash.png`

Create one continuous rounded diagonal prohibition slash running bottom-left to top-right. Saturated coral-red `#FE3C00` fill with thick dark-purple outline. No circle, second bar, X, speaker, phone, text, or background.

## `Settings/gear.png`

Create one centered 8-tooth chunky settings cog with one transparent circular center hole. Cream fill with thick smooth dark-purple outline. No button shell, second gear, wrench, fragments, text, or background.

## `HUD/coin.png`

Create one nearly front-facing chunky gold toy coin with a beveled rim and shallow embossed spiral motif. Bright gold `#FEC901`, orange `#F08A00` depth, restrained dark-purple keyline. No letters, numbers, currency symbols, stack, text, or background.

## `HUD/heart.png`

Create one classic rounded red heart with a soft pointed bottom. Coral-red `#FE3C00`, warm orange-red bevel, thick dark-purple outline. No number, broken-heart treatment, anatomy, face, text, or background.

## `HUD/plus.png`

Create one compact round green plastic badge with one centered chunky cream plus, equal rounded arms, green `#00D44C`, and thick dark-purple outlines. No medical styling, coin, extra marks, text, or background.
